# Retrieval Practice — 자체 회상 강제 가이드

## 원리

Roediger & Karpicke (2006) — *읽기/복습보다 회상이 학습 효과 압도적으로 높다*. "Testing effect" 인용 15K+.

> 핵심: 학습자가 자료를 *닫고* 머릿속에서 끌어내는 행위가 *읽는 행위*보다 5~10배 강한 기억 형성.

## 우리 적용 방식

### 1. 핵심 3줄 재정의

기존: 단순 요약 ❌
**신규**: 학습자가 *덮고 말로* 설명할 수 있어야 할 것 ✅

각 줄은 *자체 회상 시험 문제*가 되어야 함.

```markdown
### K강 핵심 3줄 (회상 점검 — 덮고 말로 설명 가능?)

1. <개념 1을 말로 설명> — 구체 수치/기법명 포함
   → 회상 점검: 이 줄을 덮고 1분 안에 친구에게 설명 가능?

2. <개념 2 트레이드오프 또는 결정적 차이>
   → 회상 점검: "왜 A 대신 B?" 답할 수 있는가?

3. <개념 3 적용 시 흔한 함정 또는 핵심 패턴>
   → 회상 점검: 실제 시나리오에서 이 패턴 떠올릴 수 있는가?
```

### 2. 강의 중간 회상 prompt

본문 중간에도 *명시적 회상 강제*. 새 개념 도입 직후:

```markdown
> **회상 점검**: 위 개념을 자기 말로 다시 설명할 수 있는가? 못 하면 다시 읽기.
```

길이 강의 (300줄+) 에서는 2~4회 명시 권장. 짧은 강의는 1회.

### 3. Worked Example 후 Faded → 독립 풀이

(Worked Examples 가이드 참조)
- 완성 예제 본 후 → Faded 예제는 학습자 회상 강제
- 독립 풀이는 완전 회상

### 4. 시리즈 끝 (마지막 강의) 종합 회상

시리즈 마지막 강의는 *시리즈 전체 회상*도 포함:

```markdown
### 시리즈 종합 회상

이 시리즈가 끝난 지금, 다음을 *덮고* 답할 수 있는가?

1. (1강 핵심) ...
2. (2강 핵심) ...
3. ...

답 못 하면 → 해당 강의로 돌아가서 회상 점검.
```

## 회상 vs 단순 요약 구분

| 단순 요약 | 회상 도구 |
|---|---|
| "A 강의에서 X / Y / Z를 다뤘다" | "X와 Y의 차이를 말해보라" |
| "Git에는 merge와 rebase가 있다" | "merge 대신 rebase를 쓰는 결정 기준은?" |
| "PATH 환경 변수가 중요하다" | "PATH 잘못 설정 시 어떤 증상이 어디서?" |

요약은 *재인*(recognition), 회상은 *재생*(recall). 학습 효과는 후자만 강함.

## Spaced Repetition (간격 반복)

이상적: 강의 → 1일 후 회상 → 1주 후 회상 → 1달 후 회상.

우리 적용:
- 다음 강의 도입부에 *직전 강의 회상 질문* 1~2개
- 시리즈 종합 회상 (마지막 강의)
- 트랙 종료 시 트랙 회상 (선택)

```markdown
### 다음 강의 도입부 패턴

지난 강의(<TRACK>-L-(K-1))에서 다룬 다음을 *덮고* 답해보자:

1. (이전 강의 핵심 질문)
2. (이전 강의 핵심 질문)

답 못 하면 → 이전 강의 회복 점검.
```

## 검증 grep 패턴

```bash
# 회상 점검 마커
RETRIEVAL_PROMPTS=$(grep -cE '회상 점검|덮고.*설명|덮고.*답|회상 시험' "$FILE")

# 핵심 3줄에 회상 도구 형태
CORE3_AS_RECALL=$(awk '/^### .*핵심 3줄/{f=1; next} /^---$|^## /{f=0} f' "$FILE" | grep -cE '회상|덮고|말로|설명 가능')

# 다음/이전 강의 회상 (Spaced Repetition)
SPACED_RETRIEVAL=$(grep -cE '지난 강의.*답해|이전 강의.*회상|덮고.*직전' "$FILE")

# 단순 요약 (감점)
PLAIN_SUMMARY=$(awk '/^### .*핵심 3줄/{f=1; next} /^---$|^## /{f=0} f' "$FILE" | grep -cE '^[0-9]+\. .* (다뤘다|배웠다|있다)$')
```

## 검증 기준

- ✅ 핵심 3줄에 회상 도구 형태 (단순 요약 X)
- ✅ 본문 중간 회상 점검 마커 1+ (긴 강의)
- ✅ 직전 강의 회상 (2강 이상) — Spaced Repetition
- ❌ 단순 요약 패턴 ("X를 다뤘다", "Y를 배웠다")

## 학습자 점검 도구 권장

핵심 3줄 끝에 체크박스:

```markdown
- [ ] 1번을 덮고 말로 설명할 수 있다
- [ ] 2번을 덮고 말로 설명할 수 있다
- [ ] 3번을 덮고 말로 설명할 수 있다

3개 모두 ✅ → 다음 강의로
못 하면 → 해당 섹션 다시 읽고 회상 재시도
```
