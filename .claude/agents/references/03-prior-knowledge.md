# 선행 지식 가정 명시 가이드

## 원리

학습자가 *어디서 막혔을 때 어디로 돌아갈지* 모르면 좌절 → 학습 포기. 인지 부하 이론에서도 "선행 지식 활성화"가 본질 학습 부하 (germane load)를 최적화하는 출발.

> 핵심: 모든 강의는 학습자에게 "이 강의 진입 *전*에 알아야 할 것"을 *명시*해야 한다.

## 우리 적용 구조

### `### 시작하기 전` 섹션 필수 3요소

```markdown
### 시작하기 전

**선행 강의 (반드시)**:
- 직전 강의 <TRACK>-L-(K-1): <어떤 개념 가져왔는지 한 줄>
- 다른 트랙/시리즈 (있다면): <트랙-시리즈>: <개념>

**선행 강의 (권장)**:
- <선택적 강의>: <개념> — 모르면 막힐 가능성

**필요한 환경/도구**:
- macOS / Linux / Windows WSL 등
- 도구명 + 버전 명시

```bash
# 환경 자동 체크
which python3 && python3 --version  # 3.10+
which git && git --version           # 2.30+
```

**막힐 때 돌아갈 곳**:
- 개념 X가 흐릿하면 → <TRACK>-L-(K-1)의 Y 섹션
- 도구 셋업 모르면 → A-1-1 (또는 적절한 강의)
- 환경 변수 헷갈리면 → A-1-2 (또는 적절한 강의)
```

### 4요소 자세히

#### 1. 선행 강의 (반드시)

직전 강의 + 다른 트랙 의존성. *없으면 이 강의가 흐릿하다*는 강한 선행.

#### 2. 선행 강의 (권장)

선택적. 모르면 막힐 가능성 있는 것. 우회 가능.

#### 3. 필요한 환경/도구

자동 체크 명령 포함:

```bash
# 자기 환경 즉시 점검
python3 --version
git --version
docker --version
aws --version
```

학습자가 강의 들어가기 전 1분 안에 환경 OK 확인 가능해야 함.

#### 4. 막힐 때 돌아갈 곳

각 개념별로 *명시*. 학습 중 혼란 시 어디로 돌아갈지 *지도* 역할.

**나쁜 예시**:
- "이해 안 되면 이전 강의 다시 봐" — 어디?

**좋은 예시**:
- "PATH 개념 흐릿하면 → A-1-2의 '검색 순서 알고리즘' 섹션"
- "subshell 모르면 → A-1-2의 '자식 프로세스 상속' 섹션"

## 첫 강의 (시리즈 1강) 처리

선행 강의 없음. 그래도 섹션 유지:

```markdown
### 시작하기 전

**선행 강의**: 없음 (시리즈 첫 강의 또는 트랙 첫 강의)

**필요한 환경/도구**:
- macOS / Linux 터미널
- (자동 체크 명령)

**막힐 때 돌아갈 곳**:
- 터미널 자체가 처음이면 → (해당 강의)
- 셸 설정 모르면 → (해당 강의)
```

## 트랙 첫 시리즈 첫 강의 (예: A-1-1)

가장 입문. 선행 0. "막힐 때 돌아갈 곳"도 *외부 자료* (책/공식 문서) 명시 OK.

```markdown
**막힐 때 돌아갈 곳**:
- macOS 설치 안 했으면 → Apple 공식 가이드
- 일반 컴퓨터 사용이 처음이면 → CS50 0주차 (한국어 자막 있음)
```

## 검증 grep 패턴

```bash
# 섹션 존재
PRECEDING_SECTION=$(grep -c '^### 시작하기 전' "$FILE")

# 4요소 (선행 / 환경 / 막힐 때 / 자동 체크)
HAS_PRECEDING=$(awk '/^### 시작하기 전/{f=1; next} /^---$|^### /{f=0} f' "$FILE" | grep -cE '선행 강의|선행 시리즈')
HAS_ENVIRONMENT=$(awk '/^### 시작하기 전/{f=1; next} /^---$|^### /{f=0} f' "$FILE" | grep -cE '환경|도구|버전')
HAS_STUCK_HINT=$(awk '/^### 시작하기 전/{f=1; next} /^---$|^### /{f=0} f' "$FILE" | grep -cE '막힐 때|돌아갈|이해 안')
HAS_AUTO_CHECK=$(awk '/^### 시작하기 전/{f=1; next} /^---$|^### /{f=0} f' "$FILE" | grep -cE 'which |--version|version$')

# 모호 표현 (감점)
VAGUE_FALLBACK=$(awk '/^### 시작하기 전/{f=1; next} /^---$|^### /{f=0} f' "$FILE" | grep -cE '이전 강의 다시|모르면 찾아|어디든')
```

## 검증 기준

- ✅ `### 시작하기 전` 섹션 1개 존재
- ✅ 선행 강의 명시 (또는 "없음 (첫 강의)")
- ✅ 환경/도구 명시
- ✅ 자동 체크 명령 1+ 포함
- ✅ "막힐 때 돌아갈 곳" 구체 강의/섹션 명시
- ❌ 모호 표현 ("이전 강의 다시", "어디든")
