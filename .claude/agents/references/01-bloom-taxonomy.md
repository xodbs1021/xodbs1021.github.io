# Bloom's Taxonomy — 학습 목표 작성 가이드

## 원리

Benjamin Bloom (1956) + Anderson & Krathwohl 개정판 (2001). 학습을 6단계 인지 위계로 분류. 각 단계마다 *측정 가능한 동사* 사용.

> 핵심: "외워라 / 이해해라" 같은 모호한 동사는 학습 목표 X. **관찰 가능한 행위**만 OK.

## 6단계 인지 위계 (낮음 → 높음)

| 단계 | 정의 | 측정 동사 (한국어) | 측정 동사 (영어) |
|---|---|---|---|
| **1. 기억 (Remember)** | 사실/용어 회상 | 정의한다, 나열한다, 식별한다, 인용한다 | define, list, identify, recall |
| **2. 이해 (Understand)** | 개념 설명/요약 | 설명한다, 구분한다, 요약한다, 분류한다, 비교한다 | explain, distinguish, summarize, classify, compare |
| **3. 적용 (Apply)** | 새 상황에 사용 | 적용한다, 구현한다, 실행한다, 사용한다, 해결한다 | apply, implement, execute, use, solve |
| **4. 분석 (Analyze)** | 부분 분해/관계 파악 | 분석한다, 분해한다, 구조화한다, 원인을 찾는다 | analyze, decompose, structure, attribute |
| **5. 평가 (Evaluate)** | 기준에 따라 판단 | 평가한다, 비판한다, 정당화한다, 선택한다 | evaluate, critique, justify, select |
| **6. 창조 (Create)** | 새 산출물 만들기 | 설계한다, 구성한다, 통합한다, 작성한다 | design, construct, integrate, compose |

## 금지 동사 (모호함)

- ❌ 외운다 / 안다 / 이해한다 — 측정 불가
- ❌ 익숙해진다 / 친해진다 / 감을 잡는다 — 주관적
- ❌ 알게 된다 / 배운다 / 익힌다 — 결과 모호

## 학습 목표 작성 패턴

### 좋은 예시

```markdown
### 학습 목표

이 강의가 끝나면 학습자는 다음을 할 수 있다:

1. **식별 [기억]**: 임의의 프롬프트에서 4요소(사용자/호스트/경로/권한)를 식별
2. **구분 [이해]**: 터미널·콘솔·셸·CLI 4개 용어를 한 문장으로 구분
3. **적용 [적용]**: EC2 SSH 접속 직후 `whoami`/`hostname`/`pwd`로 환경 검증
4. **평가 [평가]**: `%` vs `$` vs `#` 권한 기호로 sudo 필요 여부 판단
```

각 동사에 [Bloom 단계] 명시. 학습자 + lesson-quality-guard가 동사 진위 검증 가능.

### 나쁜 예시

```markdown
### 학습 목표

- 터미널을 *이해한다* — 측정 불가
- 명령어에 *익숙해진다* — 주관적
- 프롬프트를 *안다* — 모호
```

## 학습 목표 갯수

| 갯수 | 평가 |
|---|---|
| 1~2개 | 너무 적음 (강의 깊이 부족 의심) |
| **3~5개** | **권장** |
| 6+ | 너무 많음 (인지 부하 / 강의 흐려짐) |

## 검증 grep 패턴

```bash
LO_SECTION=$(grep -c '^### 학습 목표' "$FILE")
LO_COUNT=$(awk '/^### 학습 목표/{f=1; next} /^---$/{f=0} f && /^[0-9]+\. /' "$FILE" | wc -l)

# 모호 동사 (있으면 ❌)
VAGUE_VERBS=$(awk '/^### 학습 목표/{f=1; next} /^---$/{f=0} f' "$FILE" | grep -cE '이해한다|안다|익숙|친해|감을 잡|배운다|익힌다')

# Bloom 동사 (있어야 ✅)
BLOOM_VERBS=$(awk '/^### 학습 목표/{f=1; next} /^---$/{f=0} f' "$FILE" | grep -cE '정의|나열|식별|설명|구분|요약|분류|비교|적용|구현|실행|사용|해결|분석|분해|구조화|평가|비판|정당화|선택|설계|구성|통합|작성')

# Bloom 단계 명시 ([기억]/[이해]/[적용]/[분석]/[평가]/[창조])
STAGE_TAGS=$(awk '/^### 학습 목표/{f=1; next} /^---$/{f=0} f' "$FILE" | grep -cE '\[(기억|이해|적용|분석|평가|창조)\]')
```

## 검증 기준

- ✅ `### 학습 목표` 섹션 1개 존재
- ✅ 학습 목표 3~5개
- ✅ Bloom 측정 동사 hit ≥ 학습 목표 갯수
- ✅ 모호 동사 0
- ✅ Bloom 단계 태그 [...] 명시
