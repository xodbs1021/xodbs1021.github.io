# storyboard — pokeclip-audio-assignment-user-state

## 영상 1 AutoAssignRestore (반복 약 12초 = 360프레임, 휴대폰판)

주장: 자동 배정은 처음 쓰기 전 체크를 컬렉션마다 남겨 두고, 끄면 각 컬렉션이 자기 원래 체크로 돌아간다. 방송·녹화·리플레이 버퍼 중에는 되돌리기를 미룬다.

화면: 체크 격자. 열 = OBS 트랙 1–6(머리 「1」…「6」), 행 = 소스 2개(「Tone」 · 「마이크」). 격자 위에 컬렉션 탭 「컬렉션 A」 / 「컬렉션 B」(지금 것 강조). 격자 오른쪽 아래에 백업 상자 「원래 체크 백업」 — 컬렉션별 줄 「A」 「B」가 생기고 지워진다. 칸: 체크됨 = ink 채움, 비어 있음 = 테두리만, 자동 배정이 바꾼 칸 = accent 채움, 되돌린 칸 = 잠깐 accent 테두리 번쩍.

값(PR #195 리뷰 3판 실측과 같게):
- 컬렉션 A 원래: Tone 1–6 전부, 마이크 1–6 전부 → 자동 배정 뒤 Tone 1,3 · 마이크 1,2
- 컬렉션 B 원래: Tone 1–6 전부, 마이크 1,2,3 → 자동 배정 뒤 Tone 1,3 · 마이크 1,2

| 프레임 | 무엇 |
|---|---|
| 0–20 | 「컬렉션 A」 탭, 격자에 원래 체크(전부 체크) |
| 20–60 | 자동 배정 적용: Tone 2,4,5,6 · 마이크 3,4,5,6 체크가 빠지고 Tone 3 · 마이크 2가 accent. 백업 상자에 「A」 줄 |
| 60–80 | 탭이 「컬렉션 B」로. 격자가 B의 원래 체크(Tone 전부, 마이크 1,2,3) |
| 80–120 | 자동 배정 적용(Tone 1,3 · 마이크 1,2). 백업 상자에 「B」 줄 |
| 120–150 | Tag 「리플레이 버퍼 중」(muted) 이 뜨고, 스위치 「자동 배정 끔」 |
| 150–190 | 격자 그대로 + Tag 「되돌리기 보류」(muted, 점선) |
| 190–210 | Tag 「리플레이 버퍼 정지」 |
| 210–250 | B 격자가 원래 체크로 돌아온다(Tone 전부, 마이크 1,2,3 — 되돌린 칸 번쩍). 백업 상자에서 「B」 줄만 지워지고 「A」 줄은 남는다 |
| 250–270 | 탭이 「컬렉션 A」로 |
| 270–310 | A 격자가 A의 원래 체크로(Tone 전부, 마이크 전부). 백업 상자 「A」 줄 지워짐 |
| 310–360 | 끝 프레임 유지: Tag 「각자 원래 체크로」(accent) (posterFrame 340) |

끝 프레임은 A가 원래 체크로 돌아온 모습 + 「각자 원래 체크로」. 혼자서도 「끄면 컬렉션마다 원래 체크로 돌아간다」가 읽혀야 한다. 끝 프레임에 B도 원래 체크였음을 보이고 싶으면 작은 B 격자 축소판을 옆에 둬도 된다(필수 아님).

- 휴대폰판: 탭을 위, 격자를 가운데(칸 크게), 백업 상자와 Tag를 아래. 글자 48px 이상.

## 그림 2 대응 도식(Mermaid flowchart TB, 폭 ≤ 440px)

고급 출력에서 방송 트랙 = OBS 트랙 2인 경우. OBS 트랙 1(믹서 0) · 트랙 2(믹서 1, 본방) · 트랙 3–6. 서버 audio1 ← 본방 오디오 인코더 공유(믹서 1, 강조). audio2 ← 트랙 2(본방 트랙, 자동 배정이 건드리지 않음). audio3–6 ← 트랙 3–6(스템). 「믹서 0 고정이면 audio1 ≠ 본방」을 점선으로.
