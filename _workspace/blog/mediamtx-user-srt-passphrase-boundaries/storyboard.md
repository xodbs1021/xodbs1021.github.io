# storyboard — AuthBodyWait (11초, 330프레임, 반복, 휴대폰판 있음, kind 재구성)

주장: HTTP 인증의 2xx 본문을 기다리는 동안 같은 경로 관리자에 들어온 GET /v3/paths/list 도 기다린다. v1.21.3과 #6306 모두 같고, v1.21.2는 본문을 읽지 않는다.

- 0–0.5초: 송출자 · MediaMTX 경로 관리자 · 인증 응답기.
- 0.5초: SRT 접속(송출자 → MediaMTX). 1.3초: 인증 요청(MediaMTX → 응답기).
- 2.1초: 「200 헤더만」 회색 점선으로 돌아옴. 시계 「본문 대기 0.0초」 시작, MediaMTX 상자 회색.
- 2.6초: 아래 「GET /v3/paths/list · 대기 중」, 막대가 차오름.
- 7.1초: 「본문 도착」 청록, 시계 1.0초. 7.7초: 「사용자 암호로 수락」. 8.2초: 목록 「응답 · 1.0초 뒤」 청록.
- 끝: 「v1.21.3 · #6306 모두 같음, v1.21.2는 본문을 읽지 않음」, 정지.
숫자: 본문 1초 지연 조건의 목록 완료 중앙값(v1.21.3 1,004.67ms, #6306 아래 측정값). 헤더 뒤 1초는 영상에서 약 5초로 늘려 보임.
휴대폰판: 세 참가자를 위아래로, 목록 상자는 MediaMTX 오른쪽.
