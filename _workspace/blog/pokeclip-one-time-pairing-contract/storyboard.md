# 콘티 — PairingCodeLifetime (12초 · 360프레임 · 포스터 350 · 휴대폰판 있음)

- 위: 시간축(발급 · 10분 만료 · 청소 눈금)과 「만료 뒤 1시간 보관」 괄호. 재생점이 20→290프레임 동안 지나간다. 시간축 길이는 설명용.
- 줄 1 「쓴 코드」: 유효(짧게) → 「200 교환」 → 사용됨 · 행 남음 → 「다시 입력 → 409」 → 청소 뒤 행 없음(점선) → 「→ 404」.
- 줄 2 「쓰지 않은 코드」: 유효(10분) → 만료 · 행 남음 → 「입력 → 410」 → 청소 뒤 행 없음 → 「→ 404」.
- 끝 프레임: 두 줄과 이름표가 모두 보여 혼자서도 뜻이 통한다.
- 정적 그림: Mermaid 시퀀스(웹 · Auth · 플러그인, 200/409/410/429). 휴대폰 폭 때문에 init 으로 참가자 폭을 줄이고 메시지를 짧게 했다(폭 430px).
