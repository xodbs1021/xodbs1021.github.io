# 콘티

## FrameToPlayer (반복 영상 12초 · 360프레임 · 30fps, kind 개념도 · 수치 실측)

주장 하나: 화면 한 줄기의 초당 바이트가 단계마다 줄고, CDN에서 같은 조각이 여러 시청자에게 퍼진다.

- 0–12: 위에 「초당 186.6MB」(검정), 꽉 찬 가로 막대, 「압축 전 · RGB 24비트」. 아래 단계 상자 여섯(카메라·화면 / 색 줄이기 / 압축 / 송출 / 포장 / CDN)과 오른쪽 시청자 동그라미 셋(점선 연결).
- 48–72: 네모 표식이 「색 줄이기」로 이동, 막대가 절반으로 줄고 숫자 「초당 93.3MB」, 원래 끝에 186.6MB 눈금.
- 108–132: 「압축」으로 이동, 막대가 거의 사라짐(10px), 숫자 청록 「초당 0.77MB」, 93.3MB 눈금 추가.
- 156–252: 송출 → 포장 → CDN으로 차례로 이동(숫자 그대로).
- 270–300: CDN 상자에서 표식 셋이 갈라져 시청자 셋으로, 선이 청록 실선, 시청자 칠해짐.
- 300–360: 멈춤. 포스터 340(끝 프레임만으로 186.6 · 93.3 눈금과 0.77, 세 갈래가 보임).

휴대폰판(1080×1350): 막대 위, 단계 상자 세로 6칸(이름 왼쪽 · 부가 오른쪽, 48px), 시청자 셋은 CDN 상자 오른쪽 위로.
