# storyboard — webrtc-deep-dive

## 영상 1 `IceCandidatePairs` (반복 11초, 30fps, 330프레임, 휴대폰판 있음, 개념도)

주장 하나: ICE(RFC 8445)는 양쪽이 모은 후보 주소(host · srflx · relay)를 짝지어 연결 확인을 해 보고, 통한 쌍 하나를 골라 미디어를 보낸다.

같은 도식(왼쪽 피어 A 의 후보 칸 3개 · 오른쪽 피어 B 의 후보 칸 3개 · 가운데 위 STUN · TURN 상자)에서 강조만 옮긴다. 생성 소재 없음, 코드로만 그림. 숫자 · 성공률 · ms · IP 주소 없음.

### 1막 — 후보 모으기 (0–125프레임)

- 0–15: 「피어 A」(왼쪽) · 「피어 B」(오른쪽) 상자, 가운데 위 「STUN 서버」 · 「TURN 서버」 작은 상자가 나타난다.
- 15: 양쪽에 「host (사설 주소)」 칸이 생긴다.
- 35–50: STUN 상자에서 양쪽 srflx 칸 자리로 회색 점선이 내려오고, 50 에 「srflx (STUN이 알려 준 공인 주소)」 칸이 생긴다.
- 70–85: TURN 상자에서 양쪽 relay 칸 자리로 회색 점선이 내려오고, 85 에 「relay (TURN 서버 주소)」 칸이 생긴다.
- 97–125: 멈춤(1초 가까이, 후보 6칸이 다 보임).

### 2막 — 연결 확인 (125–245프레임)

- 125–137: 1막의 점선이 사라진다(가운데를 쌍 선에 비워 준다). 서버 상자는 남는다.
- 125–143: host–host 선이 A→B 로 그어진다(위험색). 143 에 선 위 이름표 danger 「✕ 서로 다른 망」.
- 160–178: srflx–srflx 선(강조색). 178 에 accent 「✓」.
- 195–213: relay–relay 선(검정). 213 에 ink 「✓」.
- 213–245: 멈춤(1초).
- 그림은 세 쌍만 보인다(실제 ICE 는 모든 쌍을 우선순위대로 확인 — 본문 · 캡션이 말한다).

### 3막 — 고르기 (245–330프레임)

- 245–257: srflx 선이 굵어지고 양쪽 srflx 칸이 강조 상자로 바뀐다. relay 선 · 이름표는 회색으로 내려가고 이름표가 「✓ 예비」 가 된다.
- 250: srflx 선 아래 accent 이름표 「선택 · 미디어」.
- 255: 아래 회색 이름표(데스크톱만) 「이 예에서는 두 NAT 사이 srflx 쌍이 통함」.
- 257–330: srflx 선 위로 점(패킷) 3개가 A→B 로 계속 흐른다. 끝 상태는 265 에 완성, 330 까지 유지(포스터 320).

### 끝 프레임(포스터 320)

피어 A · B 각자 후보 3칸, host 쌍 ✕ 서로 다른 망, srflx 쌍 굵은 강조선 + ✓ + 선택 · 미디어 + 패킷, relay 쌍 회색 ✓ 예비, 위에 STUN · TURN 상자, 아래 각주. 혼자서 「세 쌍을 확인해 통한 srflx 쌍을 골랐다」 가 읽힌다.

### 배치

- 데스크톱 1920×1080: 피어 상자 y 110–210(A x 100–660, B x 1260–1820), 서버 상자 y 120–200(STUN x 690–940, TURN x 980–1230). 후보 칸 560×130 두 줄 글자(종류 42px · 설명 36px), host y 290 · srflx y 490 · relay y 690. 쌍 선은 칸 안쪽 가장자리(660 → 1260) 가로선, 결과 이름표는 선 위 가운데(x 960), 「선택 · 미디어」 는 srflx 선 아래. 각주 y 900.
- 휴대폰판 1080×1350: 서버 상자 y 120–220(STUN x 140–500, TURN x 580–940), 피어 상자 y 300–400(A x 40–400, B x 680–1040). 후보 칸 360×120 이름표 「host」 · 「srflx」 · 「relay」 만(48px), host y 500 · srflx y 760 · relay y 1080. 결과 이름표 「✕」 · 「✓」 · 「✓ 예비」, 「선택 · 미디어」 는 srflx 줄과 relay 줄 사이 가운데. 각주 없음. 글자 48px 이상.
