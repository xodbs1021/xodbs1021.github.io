# storyboard — pokeclip-github-oidc-immutable-subject

motion-explainer 「모션그래픽」 절. 1920×1080 · 30fps · 아래 840 위로만 · `COLOR`만. 소재는 gpt-image(같은 STYLE 블록) 4장, 둘 다 같은 소재를 쓴다.

## 배역(소재)

| 이름 | 빗대는 것 | 상태 변형 |
|---|---|---|
| obj-runner | GitHub Actions 잡(코드를 도는 기계) | 두 번째 잡(Claude Code)은 같은 소재 + 이름표로 구분 |
| obj-token | OIDC 토큰(서명된 출입증) | — |
| obj-gate | AWS STS가 신뢰 정책으로 검사하는 문 | 막힘은 `danger` 이름표로 |
| obj-key | 임시 자격(시간이 지나면 끝나는 열쇠) | — |

## 영상 1 — `SubMismatch` (12초, 360프레임)

주장: 토큰의 `sub` 문자열이 신뢰 조건과 다르면 STS가 막고, 조건을 맞추면 통과한다.

| 프레임 | 무엇 |
|---|---|
| 0–40 | 배포 잡(왼쪽) · 검문(가운데) · 임시 자격(오른쪽) 등장 |
| 40 | 잡 위에 토큰, 이름표 「sub: 숫자 ID가 붙은 형식」 |
| 60 | 검문 위 이름표 「신뢰 조건: 이름 형식」(muted) |
| 80–140 | 잡 → 검문 빨간 선, 패킷이 검문 앞에서 멈춤 |
| 140 | ✕ · 「AccessDenied」 |
| 200 | 검문 위 이름표가 「신뢰 조건: 숫자 ID 형식」(accent)으로 바뀜, 빨간 표시 사라짐 |
| 220–300 | 잡 → 검문 → 임시 자격 초록 선, 패킷이 끝까지 감 |
| 300 | 「임시 자격 발급」 |
| 끝 프레임(포스터 350) | 조건이 ID 형식이고 패킷이 임시 자격까지 닿은 상태 — 혼자서도 「맞추면 통과」 |

## 영상 2 — `RefVsEnvironment` (12초, 360프레임)

주장: develop ref 단위 신뢰는 같은 브랜치의 다른 잡도 통과시키고, environment 단위로 좁히면 배포 잡만 통과한다.

| 프레임 | 무엇 |
|---|---|
| 0–40 | 위 「배포 잡」, 아래 「Claude Code 잡」, 가운데 검문, 오른쪽 임시 자격 |
| 50 | 검문 위 「신뢰 조건: develop ref」 |
| 70–150 | 두 잡 모두 → 검문 → 임시 자격, 둘 다 통과. 아래 선 옆 「조건상 통과」(danger) |
| 190 | 조건이 「신뢰 조건: environment dev-deploy」로 바뀜, 아래 경고 사라짐 |
| 210–300 | 위는 다시 끝까지 통과, 아래는 검문 앞에서 멈춤 → ✕ 「environment 없음」 |
| 끝 프레임(포스터 350) | 위만 통과, 아래 막힘 |

숫자·계정·ID 값은 그리지 않는다(형식 이름만).
