## SeekLoopTruncation (반복, 330프레임 = 11초, 30fps)

- 두 줄. 위 줄 제목 「엄격 비교 · 위치 < 시작」(위험색 강조 아님, ink), 아래 줄 제목 「1ms 여유 · 위치 < 시작 − 1ms」(accent).
- 각 줄: µs 눈금자(…010 · …011 · …012, 10.437010–10.437012초). 시작 표시(accent 세로선) = 10.4370111…(…011 과 …012 사이 0.111 지점), 이름표 「시작 10.4370111…」.
- 아래 줄에는 눈금자 전체를 덮는 옅은 accent 띠와 이름표 「시작 − 1ms 안」.
- 0–15f 등장. 20f 점(넣은 값)이 시작 선 위에서 내려와 앉음(이름표 「넣기」). 40–52f 점이 왼쪽 …011 눈금으로 미끄러짐 + 위험색 이름표 「µs 아래 버림」. 60f 판정 이름표.
  - 위 줄: 「10.437011 < 시작 → 다시 넣기」(위험색). 80f 점이 시작으로 튀어 돌아감 → 다시 깎임 … 90–240f 동안 30프레임 주기로 4번 더, 「넣기 n번째」 세는 이름표가 늘어남.
  - 아래 줄: 「시작으로 봄 → 그대로 · 넣기 1번」(accent), 그대로 머묾.
- 240–330f 정지(끝 프레임 = 포스터: 위 줄 점은 …011, 위험 이름표와 「넣기 6번째 …」, 아래 줄 점은 …011 과 accent 이름표).
- 휴대폰판 1080×1350: 두 줄을 위아래로, 눈금자 폭 880, 글자 48px 이상, 이름표 문구를 줄임(「시작 앞 → 다시 넣기」, 「여유 안 → 그대로」).
