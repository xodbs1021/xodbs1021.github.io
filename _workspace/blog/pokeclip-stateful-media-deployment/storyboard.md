# storyboard — pokeclip-stateful-media-deployment

## 영상 1 MediaBoxReplace (12초 반복, 휴대폰판)

| 프레임 | 무엇 |
|---|---|
| 0–15 | 위 줄 「API 태스크(ECS)」: 요청 → 옛 태스크. 아래 줄 「미디어 상자(EC2)」: OBS —UDP— 미디어 상자(안에 「업로드 전」 조각 2), 아래 빈 「볼륨」 |
| 25 | 새 태스크(회색 점선, 준비 중) |
| 55 | 새 태스크 정상(청록) |
| 70 | 요청 화살표가 새 태스크로 |
| 85 | 옛 태스크 회색으로 빠짐 |
| 95 | 「새 태스크가 뜬 뒤 옛 태스크를 내림」(휴대폰판 「뜬 뒤에 내림」) — 요청 손실 0은 잰 적이 없어 쓰지 않음 |
| 120 | 미디어 상자에 「TERM」 |
| 130–175 | 「최대 30초」 막대가 참 |
| 180 | 상자 내려감(회색 점선), UDP 선이 끊기고 빨간 「송출 끊김」 |
| 215–240 | 업로드 전 조각 2개가 볼륨으로 떨어져 남음 |
| 245 | 「볼륨에 남음」 |
| 285 | 상자가 다시 뜸 |
| 295 | OBS 선 다시 이어짐(청록) |
| 305 | 「300초 안 재접속 → 앞 세션을 이음」 |
| 345 | 포스터 |

끝 프레임: 위 줄은 새 태스크만 요청을 받음, 아래 줄은 상자가 다시 떴고 볼륨에 조각이 남아 있으며 재접속 이름표.
