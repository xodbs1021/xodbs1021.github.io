# x264-live-rate-control-gop — 콘티

## 영상 1: VbvBuffer (11초, 330프레임, 반복, 휴대폰판 있음)
- 주장 하나: 같은 maxrate에서 bufsize가 크면 순간 비트가 상한을 크게 넘나든다.
- 위 줄 bufsize 750k, 아래 줄 bufsize 6,000k. 각 줄에 0.25초 창 kbps 막대 40개가 0.23초(7프레임)마다 하나씩 왼쪽부터 선다(실측 10초 = 영상 약 9.3초).
- 3,000kbps 점선(maxrate). 선을 넘은 막대만 강조색(accent), 나머지는 회색(muted).
- 각 줄의 최댓값 막대(4,316 · 5,605)가 서는 순간 강조 이름표.
- 오른쪽 세로 막대 = VBV 버퍼 수위 계산값(초기 90%, 프레임마다 maxrate/24 채우고 프레임 크기만큼 비움) — 큰 장면(2–3초)에서 750k는 20%까지, 6,000k는 64% 근처까지 내려감.
- 끝 프레임(포스터, 320): 막대 40개 전부, 이름표 둘, 수위 막대. 이 한 장으로 「작은 버퍼 = 선 근처, 큰 버퍼 = 선 위로 크게」가 읽힌다.
- 휴대폰판: 같은 배치를 세로로, 글자 48px, 범례 「점선 3,000」, 가로축 눈금 생략.
- 수치 출처: measure/b4-vbv-bufsize.txt, b4-vbv-series.json
