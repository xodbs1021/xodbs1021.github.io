# B4 bufsize 두 값의 순간 비트레이트와 HLS BANDWIDTH (2026-11-13, AI(Claude Code) 실행, FFmpeg 9.0.2, x264 core 165 r3222)
입력: Sintel 예고편 10초 무손실 발췌(ref.mkv, 1920x1080 24fps 240프레임)
ffmpeg -i ref.mkv -c:v libx264 -preset veryfast -tune zerolatency -threads 4 -b:v 3000k -maxrate 3000k -bufsize 750k -g 48 -sc_threshold 0 -f mpegts vbv_750.ts
ffmpeg -i ref.mkv -c:v libx264 -preset veryfast -tune zerolatency -threads 4 -b:v 3000k -maxrate 3000k -bufsize 6000k -g 48 -sc_threshold 0 -f mpegts vbv_6000.ts
프레임 크기: ffprobe -v error -select_streams v -show_entries packet=pts_time,size,flags -of csv=p=0 vbv_X.ts (영상 ES 바이트)

VBV 상한(계산): 길이 T초 구간의 비트 ≤ maxrate×T + bufsize → 2초 구간 최대 750k: 3,375kbps, 6000k: 6,000kbps
