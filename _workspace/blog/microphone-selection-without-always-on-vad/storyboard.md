# storyboard — microphone-selection-without-always-on-vad

## 영상 1 TrackPickInClip (반복 약 12초 = 360프레임, 휴대폰판)

주장: 상시 전 트랙 VAD는 방송 내내 여섯 트랙을 분석하고도 게임 대사와 마이크를 둘 다 「음성」으로 잡는다. 대신 사람이 고른 클립 구간 안에서만 트랙별 파형을 보고, 한 트랙만 켜서 들어 보고, 그 트랙을 자막 입력으로 고른다(자막 생성은 아직 설계).

위 줄 「상시 전 트랙 VAD(뺀 설계)」: 트랙 6줄(얇은 막대, 이름 「믹스」「마이크」「게임」「디스코드」「BGM」「기타」), 왼쪽에서 오른쪽으로 흐르는 긴 시간축. 스캐너(세로 막대)가 계속 오른쪽으로 쓸고 지나간 자리는 회색으로 칠해진다(상시 연산).
아래 줄 「클립 구간 안에서 고르기」: 같은 6줄, 시간축 가운데에 구간 괄호.

| 프레임 | 무엇 |
|---|---|
| 0–20 | 두 줄 제목, 위 트랙 6줄 |
| 20–130 | 위 줄: 스캐너가 쓸고 지나가며 「마이크」와 「게임」 줄에 「음성」 Tag가 둘 다 뜬다. 끝에 빨간 Tag 「게임 대사도 음성」 |
| 130–160 | 아래 줄 등장, 구간 괄호가 펼쳐진다(「클립 구간」) |
| 160–210 | 구간 안에서만 6줄에 파형이 그려진다(밖은 빈 줄). 파형 모양은 설명용(마이크 · 게임 · BGM 줄에 높낮이, 디스코드 · 기타는 평평) |
| 210–270 | 「마이크」 줄만 켜지고(강조색) 나머지 줄은 흐려진다. Tag 「한 트랙만 켜서 듣기」 |
| 270–310 | 「마이크」 줄에서 오른쪽 「자막 입력」 상자(점선)로 화살표. 상자 아래 muted 「설계」 |
| 310–360 | 끝 프레임 유지(posterFrame 340) |

끝 프레임: 위 줄 전체가 회색으로 칠해진 상시 분석 + 빨간 「게임 대사도 음성」, 아래 줄 구간 안 파형 + 마이크만 강조 + 점선 「자막 입력(설계)」. 혼자서도 「상시 분석 대신 구간 안에서 한 트랙을 골랐다」가 읽혀야 한다.

- 색: 위 줄 스캐너 = muted, 「음성」 Tag = ink, 경고 = danger, 아래 줄 선택 경로 = accent, 자막 입력 = 점선 muted.
- 휴대폰판: 위 줄과 아래 줄을 세로로 쌓되 트랙 이름은 2글자 이내 약칭 금지 — 이름이 길면 6줄 대신 「믹스 · 마이크 · 게임 · BGM」 4줄로 줄여도 된다(두 줄 모두 같게). 글자 48px 이상.

## 그림 2 두 경로 결정도(Mermaid flowchart TB, 폭 ≤ 440px)

자막을 만들 소리 고르기 → 사람이 편집기에 있음? 예: 구간 트랙 파형(구현) → 트랙 넣고 빼며 듣기(구현) → 고른 트랙을 STT로(설계, 자막 생성 코드 없음). 아니오(원클릭 자동): 템플릿의 지정 트랙(설계) → 렌더 전 무음 검사(설계). 구현 노드는 실선 강조, 설계 노드는 점선.
