# storyboard — pokeclip-media-timeline-over-wall-clock

## 영상 1 — ChapterRule (반복 11초, 개념도, 휴대폰판 있음)

무엇을 보여 주나: 섞기 규칙에서 영상 띠는 끊기지 않고, 표시 시각만 장 단위로 이어지거나 건너뛰거나 조금 뒤로 간다.

| 프레임(30fps) | 장면 |
|---|---|
| 0–60 | 조각 1–3이 차례로 붙고 위 줄에 0:00 · 0:04 · 0:08. 이름표 「차이가 문턱 안 → 이어 적기」. 아래 「장 1」 띠가 강조색 |
| 120–210 | 조각 4가 붙고 표시 시각이 2:12로 건너뜀(「+2분」 회색). 이름표 「틈이 문턱 밖 → 새 장」. 장 1은 회색, 「장 2」가 강조색 |
| 210–275 | 조각 5가 붙고 표시 시각이 앞 조각 끝 2:16에서 2:15.7로 왼쪽으로 당겨짐(「−0.3초」 회색). 「장 3」이 열리고 강조색이 장 3으로. 이름표 「일찍 옴 → 최대 999ms 당기고 새 장」(강조색) |
| 275–330 | 이름표 「영상은 이어지고, 표시 시각만 바뀝니다」. 아래에 세 단계 요약(장 1·2·3)이 단계마다 나타나 끝까지 남음. 포스터 = 320 |

값은 설명용(조각 4초, 틈 2분, 일찍 옴 0.3초). 실패가 아니므로 danger 색을 쓰지 않는다. 강조색은 지금 장과 지금 단계 하나만.
