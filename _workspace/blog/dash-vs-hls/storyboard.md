# dash-vs-hls 콘티

## 영상 1 — TemplateVsReload (330프레임 · 11초, 반복 영상, 휴대폰판 있음)

주장: HLS 플레이어는 목록을 다시 받아야 다음 조각 이름을 알고, DASH 플레이어는 SegmentTemplate 규칙과 시계로 번호를 계산한다.

- 위: 2초 조각 12 · 13 · 14번. 13번은 40, 14번은 170에 완성(살짝 커짐).
- 왼쪽 HLS 칸: 완성마다 「목록 다시 받기 → 새 줄 확인」, 「GET seg13.m4s」(실선 = 네트워크 요청).
- 오른쪽 DASH 칸: 「시계 t=26초 → 13번 계산」(점선 = 로컬 계산), 「GET seg-13.m4s」. 14번도 같음(t=28초).
- 아래 「네트워크 요청 N번」이 실제 요청 칸 수를 셈(HLS 4, DASH 2).
- 끝 프레임(포스터 320): 칸 8개와 4번 · 2번.

시각 · 번호는 설명용(startNumber 1, 2초 조각). 휴대폰판은 같은 두 칸, 글자 48px, 칸 문구 축약.
