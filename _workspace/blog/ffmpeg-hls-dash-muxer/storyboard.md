# ffmpeg-hls-dash-muxer — 콘티

## 영상 1: SharedSegments (반복 11초, 330프레임, 휴대폰판 있음)

주장: HLS와 DASH를 출력 둘로 쓰면 인코더 둘이 조각을 두 벌 만들고, dash 먹서 -hls_playlist 1이면 인코더 하나가 만든 조각 한 벌을 두 목록이 함께 가리킨다.

- 0–0.5초: 위 칸 「출력 둘: -f hls 와 -f dash」(위험색) — 입력 20초 → x264 ① · x264 ② 두 상자. 아래 칸 「한 출력: -f dash -hls_playlist 1」(강조색) — 입력 → x264 ① 한 상자.
- 1–5.7초: 2초 조각 칸이 왼쪽부터 하나씩 10개 찬다. 위 칸은 HLS 줄과 DASH 줄 두 줄, 아래 칸은 한 줄.
- 6초: 아래 칸에 manifest.mpd · media_0.m3u8 상자가 뜨고, 두 상자에서 같은 조각 줄로 화살표가 그려진다.
- 7.4초~: 합계 이름표. 위 「인코더 2 · 조각 두 벌 15.1MB」, 아래 「인코더 1 · 조각 한 벌 7.56MB」. 끝까지 멈춤(포스터 = 300프레임).
- 휴대폰판: 줄 이름을 칸 위 글자(「x264 ① → HLS 조각」 등)로, 입력 상자 생략. 글자 48px.
- 수치 출처: measure/c1-c2-two-outputs-vs-hls-playlist.txt (조각 10개, 15,117,404 / 7,558,696바이트).
