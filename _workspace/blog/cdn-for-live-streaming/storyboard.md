## CoalesceTiers (반복 영상 12초, 360프레임, kind 재구성)

주장: 새 조각 하나에 몰린 요청 200건이 엣지 4대 → 실드 1대 → 원본 1건으로 줄어듭니다(nginx 1.31.3 실측, 합치기 켬 6/6회).

| 프레임 | 무엇이 |
|---|---|
| 0–12 | 시청자 200명(회색 빈 점 격자) · 엣지 1–4 · 실드 · 원본 상자와 연결선이 나타남 |
| 14–90 | 요청 점 200개가 시청자 격자에서 엣지로 날아감(i % 4 → 엣지 i), 엣지 둘째 줄이 1건 → 50건으로 늘어남. 「새 조각 요청 200건」 이름표 |
| 104–134 | 엣지마다 점 하나만 실드로 올라감, 엣지 둘째 줄 「1건만 위로」, 「실드에 4건」 이름표 |
| 144–174 | 실드에서 점 하나만 원본으로, 「원본에 1건」(청록) 이름표, 원본 상자 청록 |
| 196–272 | 청록 응답 점: 원본 → 실드 → 엣지 4대 → 시청자 200명, 상자 · 점이 청록으로 |
| 272–360 | 끝 상태 유지(3초) — 포스터 330 |

끝 프레임(포스터): 시청자 점 200개 청록, 엣지 「50건 응답」, 「실드에 4건」, 「원본에 1건」. 혼자서도 200 → 4 → 1 이 읽힘.

휴대폰판(1080×1350): 위 20×10 격자, 가운데 엣지 4칸 한 줄(둘째 줄 「1건만」 · 「50건」), 아래 실드 · 원본 상자, 오른쪽에 개수 이름표. 글자 48px 이상.

색: 기본 ink, 응답 · 성공 accent, 회색 연결선 line. 위험색 없음.
