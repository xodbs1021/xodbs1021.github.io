# 콘티 — CatchupAfterStall

글: `content/posts/projects/pokeclip-live-catchup-live-viewers-only.md`
성격: `재구성` — 공개 재측정(`measure/raw/drift-*.json`)의 지연 표본을 시간 · 지연 축에 비례해 다시 그린다. 표본은 1초 간격으로 줄였다.

## 주장 하나

끊긴 뒤 따라잡기를 꺼 두면 밀린 지연이 그대로 남는다. 앱 규칙은 조금 밀리면 배속으로 목표까지 좁히고, 10초를 넘게 밀리면 점프한다. WebKit 은 점프만 하므로 조금 밀린 경우엔 끔과 같이 남는다.

## 장면(12초 · 360프레임 · 30fps)

| 프레임 | 무엇이 |
|---|---|
| 0–20 | 두 칸(위: 6초 끊김 뒤, 아래: 13초 끊김 뒤)의 축 · 목표 지연 점선이 뜬다 |
| 20–200 | 위 칸: 재생점이 왼쪽에서 오른쪽으로 가며 세 선이 그려진다. 회색 = 따라잡기 끔, 회색 점선 = WebKit 점프만, 청록 = 배속 규칙. 청록 선 끝에 지금 배속 이름표(1.1배 → 1배) |
| 200–330 | 아래 칸: 같은 방식. 끔은 높게 남고, 규칙(두 브라우저)은 놓은 직후 점프 표식과 함께 목표 근처로 떨어진다 |
| 330–360 | 멈춤(끝 프레임 = 포스터) |

끝 프레임: 두 칸 모두 끝까지 그려진 상태. 위 칸에서 청록만 목표 점선에 닿아 있고, 아래 칸은 끔만 높게 남아 있다.

## 라벨

칸 제목 · 「따라잡기 끔」 · 「WebKit 점프만」 · 「배속 규칙」 · 「목표」 · 「점프」 · 배속 이름표 · 축 눈금(초). 설명 문장은 캡션 · 본문이 맡는다.
