# whip-whep-modern-ingest 콘티

## 영상 1 — WhipRoundTrips (330프레임 · 30fps · 11초, 반복 영상, 휴대폰판 있음)

주장: WHIP 은 HTTP POST 한 번으로 SDP 를 주고받지만, 미디어가 흐르기 전에 ICE 연결 확인과 DTLS 핸드셰이크 왕복이 더 남는다(RFC 9725 Figure 1 순서: POST/201 → ICE/STUN → DTLS → RTP/RTCP).

생성 소재 없음. 코드로만 그린다. 색: 화살표 · 이름표 ink, RTP 미디어 accent, 보조 이름표 muted.

### 배치

- 시퀀스도. 왼쪽 세로선 「송출기 (OBS)」, 오른쪽 세로선 「WHIP 서버」. 시간은 위 → 아래.
- 화살표는 출발 쪽보다 도착 쪽이 조금 아래(시간이 흐름). 이름표는 화살표 위 가운데.
- 단계 이름표(HTTP · ICE · DTLS)는 왼쪽 세로선 왼편에 세로 괄호선과 함께.
- 왕복 카운터: 데스크톱은 오른쪽 세로선 오른편, 휴대폰판은 위쪽. 카운터 아래 muted 「DTLS 1.2 기준 · HTTPS 연결 수립 제외」(데스크톱은 두 줄).
