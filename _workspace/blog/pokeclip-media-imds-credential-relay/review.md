## 원천과 어긋나 고친 것

- 지시문은 aws/aws-sdk-go-v2#2316 · #3184 를 만료 의미(5절)의 근거로 들었지만, 직접 열어 보니 둘 다 만료와 무관하다. #2316 은 자격 창구의 JSON 아닌 오류 응답과 `HTTP_PROXY`, #3184 는 허용 주소의 대괄호 IPv6 처리(재현 안 됨)다. 본문에서는 #2316 을 4절(응답 꼴 · 프록시 안 탐), #3184 를 3절(허용 주소)에 두었다. 만료 근거는 SDK 소스와 공개 재측정으로 댔다.
- 「SDK 는 받은 만료까지 다시 묻지 않는다」 → 「받은 만료 − 5분(캐시 창)까지」. 재측정 C1 에서 SDK 가 보고한 만료가 창구가 보낸 값보다 정확히 5분 이르다.
- ⓐ(실제 만료 그대로)의 예로 결정 노트는 「ECS 에이전트 · EKS Pod Identity 에이전트 · Greengrass TES 관행」 을 들었지만, 공개 소스로 직접 확인한 EKS Pod Identity 에이전트(v0.2.6 `service.go` 107–113행)만 썼다.

## 남은 검증 한계

- 공개 재측정은 홉 상한(응답 TTL)을 흉내 내지 않는다. 홉 상한 동작의 근거는 AWS 문서와 비공개 실험 EC2 기록 요약이다.
- 실제 만료가 15분 안으로 들어오는 갈래는 실제 IMDS 로 관찰하지 못했다(가짜 IMDS 재측정 D1 · D4 와 저장소 시험만).
- 실험 EC2 2차의 창구는 PR 브랜치 커밋 `5462d5af` 빌드이고, 공개 재측정은 머지 커밋 `ff0ac799` 빌드다.
- 원자료 링크(`blob/main/_workspace/...`)는 main 병합 뒤에 열린다.
- date 는 임시 값(작성 시각)이다. 공개 직전에 바꾼다.
