# 콘티 — 사이드카 되감기 목록 글

## StallLadder (반복 영상 12초 · 360프레임 · 휴대폰판 있음)

주장 하나: 정체 사다리는 두 축에서 따로 잰다 — 위 축(holdAge)에서 0.5초 L1 → 2초 L2, 아래 축(stallAge)에서 5.5초 L2′ → 7.5초 L4.

| 프레임 | 무엇이 |
|---|---|
| 0–16 | 두 축 · 제목 · 눈금 · 흐린 이름표 넷이 나타남 |
| 24–114 | 위 축 재생점이 0 → 2.5초로 감. 지난 부분이 청록. 0.5초에서 「L1 재시도 당김」, 2초에서 「L2 GAP」이 청록으로 켜짐 |
| 144–294 | 아래 축 재생점이 0 → 8초. 5.5초에서 「L2′ 봉인(스위치)」이 회색(기본 끔)으로, 7.5초에서 「L4 경보」가 빨강으로 켜짐 |
| 294–360 | 정지(끝 프레임 = 포스터 340) |

- 두 축의 0 은 다른 시각이다: 위 = 조각 끝 + 2초(실렸어야 할 때), 아래 = 마지막 발행 성공. 축 아래 회색 글로 적는다.
- 지시문은 「holdAge 시간축 위에서 0.5/2/5.5/7.5」였지만 코드(`ladder.go` 1–23)에서 5.5 · 7.5 는 stallAge 축이라 두 축으로 나눠 그렸다.
- 값은 설계 상수(실측 아님) → kind=개념도.
- 휴대폰판: 글자 48px 이상, 축 900px, L4 이름표는 축 아래로.
