# 콘티 — 한 CDN 배포에서 라이브는 EC2로, 되감기는 S3로 갈랐습니다

## PipelineStop(반복 영상 10초 · 300프레임 · 휴대폰판 있음)

글의 주장 하나: **되감기 · 녹화 공정이 멈춰도 라이브 시청은 끊기지 않는다**(라이브와 녹화를 다른 주소 · 다른 원본으로 나눈 가장 큰 이유).

| 시각 | 무엇이 |
|---|---|
| 0–1초 | 상자 여섯이 차례로 뜬다: OBS → MediaMTX → 위 갈래 「/live · Media 상자」, 아래 갈래 「사이드카 · 재포장 · 업로드」 → 「S3 · /dvr · /vod」, 끝에 「플레이어」 |
| 1–4초 | 두 갈래 모두 선이 그려지고 패킷(청록)이 흐른다 |
| 4–5초 | 아래 갈래 사이드카 상자가 빨강으로 바뀌고 「멈춤」 이름표. MediaMTX → 사이드카 → S3 선의 패킷이 멈춘다. S3 → 플레이어는 이미 올린 조각이라 계속 흐른다 |
| 5–10초 | 위 갈래 패킷은 계속 흐른다. 「라이브는 계속」(청록) · 「되감기 머리가 멈춤」(빨강) 이름표가 뜬 채 머문다 |

끝 프레임(포스터, 270): 위 갈래와 S3 → 플레이어의 청록 패킷이 흐르는 중, 사이드카 빨강 · 멈춤, 두 이름표가 다 보인다.

- 수치 없음 → `kind="개념도"`. 사이드카가 멈추는 원인은 특정하지 않는다(업로드 · 재포장 · 발행 어느 것이든).
- 휴대폰판: 위에서 아래로 OBS → MediaMTX, 그 아래 왼쪽 열이 라이브 갈래, 오른쪽 열이 되감기 갈래, 맨 아래 플레이어. 글자 48px 이상.
