# review — pokeclip-round-vod (3편)

## 시각 자료 판단

- 정적: 그림 1 ECharts(실측). 「한 조각만 목표 길이를 넘었고 6초 넘는 조각은 15개 더 있었다」는 분포의 꼬리 자체가 정보라 수치 표 대신 선 그래프. 공개 골든 1,730점 전부(잘림 없음). 목표 길이 6초 점선(markLine) · seq 1627 위험색 점(markPoint) · 앞/뒤 목록 두 선. 이중 축 없음, 토큰 hex 셋만.
- 움직임: `RoundDocument` 11초 반복 + 휴대폰판(개념도). 「목록이 갈라지는 순간 → 문서 둘 → API 범위가 꼬리만 → 회차 문서로 자라며 범위가 전체로」의 순서가 주장이라 움직임으로. 끝 프레임에 고치기 전 · 뒤 두 줄이 함께 남아 포스터로도 읽힘. 띠 폭은 EXTINF 합 비례.
- 표 셋: 후보 넷(선택지 비교), decideScope 7줄(규칙 조회), 재생 시험(목록 × 결과, 휴대폰 폭에서 표 안 스크롤이 생기지 않게 3열로 줄임).
- 넣지 않음: 깨우기 흐름 Mermaid(사건 셋을 한 문장으로 충분), 지연 상한 수식, 변이 26개 표(수치 셋이면 문장), 생성 이미지.
