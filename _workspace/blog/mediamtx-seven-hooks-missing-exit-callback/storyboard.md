# storyboard — SilentExecFailure (10초, 300프레임, 반복, 휴대폰판 있음)

주장: 실행 파일이 없으면 자식이 생기지 않아 stderr 도 없고, 실패를 받는 곳은 MediaMTX 의 OnExit 뿐이다.

- 0–0.5초: 두 줄(위 v1.21.3 · OnExit 없음, 아래 #6259 · OnExit 있음)의 자식 자리(점선) · MediaMTX · 로그 상자가 나타남.
- 0.6초: 두 줄 로그에 `launched`.
- 1.2–2.4초: MediaMTX → 자식 자리로 exec 화살표.
- 2.6초: 자식 자리가 빨강 「자식 프로세스 생기지 않음」, 아래 「stderr 없음」.
- 3.7–4.7초: 실패가 되돌아옴. 위 줄은 회색 점선 「받을 곳 없음」, 아래 줄은 청록 「OnExit」.
- 5초: 아래 줄 로그에 청록 `exited: no such file`, 위 줄은 회색 「(더 없음)」. MediaMTX 상자(아래) 청록.
- 5–10초: 정지(끝 프레임 = 포스터).
