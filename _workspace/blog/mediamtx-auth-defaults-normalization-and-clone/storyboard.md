# storyboard — SharedDefaultAlias (11초, 330프레임, 반복, 휴대폰판 있음)

주장: v1.21.0에서는 전역 기본값과 conf가 같은 저장 공간을 가리켜 환경변수 하나가 둘을 함께 바꾸고, 비교가 같음이 돼 alice가 버려진다. v1.21.1은 deepClone으로 나눠 비교가 다름 → 기동 거부.

- 0–0.5초: 두 줄. 줄마다 「전역 기본값」 · 「conf」 상자, 오른쪽에 저장 공간(위 줄 하나, 아래 줄 둘) 「user: any」.
- 0.5–1.2초: 두 상자에서 저장 공간으로 화살표.
- 2초: 「환경변수 user=alice」 이름표.
- 3.2–4초: 화살표가 바뀌는 저장 공간 오른쪽으로. 위 줄은 공유 공간이 빨강 「user: alice」, 아래 줄은 conf 쪽만 청록 「user: alice」.
- 4.7초: 「비교: 같음」(빨강) / 「비교: 다름」(청록). 6초: 「이전 인증이 덮어씀 → alice 없음」 / 「충돌 → 기동 거부」.
- 6.5–11초: 정지(포스터).
