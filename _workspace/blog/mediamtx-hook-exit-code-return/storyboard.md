# storyboard — ExitCodeDiscarded (10초, 300프레임, 반복, 휴대폰판 있음)

주장: 자식의 5를 v1.20.1은 계산만 하고 버려 0을 돌려주고, v1.21.0은 그대로 돌려준다. 그 차이가 재시작 켬 · 끔 결과 줄을 바꾼다.

- 0–0.5초: 두 줄(위 v1.20.1 · return 빠짐, 아래 v1.21.0 · return 추가). 줄마다 「자식 프로세스 exit 5」 → 「ExitCode() = 5」 → 「반환값」(회색 점선).
- 0.7–1.5초: 자식 → ExitCode() 화살표.
- 3.2–4초: 위 줄은 빨강 점선 화살표와 「5는 버림」, 반환값이 빨강 「return 0」. 아래 줄은 청록 「return 5」.
- 4.7초: 결과 이름표. 위 「재시작 켬: code 0」(빨강) · 「재시작 끔: 줄 없음」(회색), 아래 「code 5」 둘(청록).
- 5–10초: 정지(포스터).
휴대폰판: 줄마다 두 단(자식 · ExitCode 위, 반환값 · 결과 아래), 글자 48px 이상.
