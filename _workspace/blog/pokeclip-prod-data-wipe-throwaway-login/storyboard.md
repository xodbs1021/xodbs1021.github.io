# storyboard — TwoDeletePaths (반복 영상 ≤12초)

주장 하나: **같은 DELETE 를 두 신분으로 했을 때 권한이 어디까지 열리는가.**

두 열(데스크톱) / 두 단(휴대폰).

- **왼쪽 — 마스터로 지우기.** 마스터가 `SET ROLE app_x` 로 앱 표를 DELETE.
  앱이 심은 트리거가 깨어나 `RESET ROLE` 로 세션 사용자(마스터)로 돌아가고, 마스터
  전용 영역에 쓴다 → danger 강조("마스터 권한으로 돎").
- **오른쪽 — 일회용 로그인으로 지우기.** 어느 역할의 멤버도 아닌 일회용 로그인(표
  권한만). DELETE 는 되고(accent), INSERT 는 막힌다. 세션 사용자가 일회용 계정이라
  트리거가 돌아갈 곳은 그 계정뿐 → 상승 없음. 비밀번호 로그인은 1시간 뒤 만료(muted 로 흐려짐).

타임라인(30fps, 300프레임 = 10초):
- 0–40: 두 열 제목 · 앱 표 등장.
- 40–95: 왼쪽 — SET ROLE 화살표 · 트리거 발동 · danger 상자 팝.
- 95–150: 오른쪽 — DELETE ✓ · INSERT ✗.
- 150–210: 오른쪽 — 일회용 로그인 muted 로 흐려짐(VALID UNTIL 1시간).
- 210–300: 끝 상태 유지.

포스터는 128프레임(왼쪽 상승이 다 보이고 오른쪽 DELETE 가 막 된 때). 포스터
용량 상한(960px WebP · AVIF 60KB) 때문에 회색 점선 상자가 뜨기 전 프레임을 골랐다.
끝 프레임: 왼쪽 danger(상승) · 오른쪽 accent(지움만, 흐려진 로그인) 동시에 보임.
글자는 이름표만, 핵심은 캡션이 다시 말한다. 휴대폰판은 글자 48px 이상.
kind=개념도(수치 없음, 구조 대비).
