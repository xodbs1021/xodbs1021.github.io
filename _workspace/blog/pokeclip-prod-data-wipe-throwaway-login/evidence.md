## 공개 링크(출처 절)

- PostgreSQL 17 문서: SET ROLE, CREATE FUNCTION, 함수 변동성, 부분 색인, 식 색인, 명시적 잠금, CREATE ROLE, 역할 속성, 권한, psql, 프로토콜 흐름.
- bash — 종료 상태(128+n). AWS — rds_superuser 역할(마스터 NOSUPERUSER), DB 스냅숏 만들기(수동 스냅숏은 만료되지 않음). MDN — Cache-Control `immutable`.
- 같은 RDS · 권한 주제 공개 글 둘.

## 미확인 · 한계

- 운영 실행 수치는 비공개 기록 요약이라 공개 링크로 재현 불가 — 공개 재측정으로 기제만 재현.
- 운영 RDS 대조 시험은 비공개. 공개 재측정이 같은 꼴을 로컬에서 재현.
- SET ROLE 전제는 실측과 일치했다(s1). 범위는 RESET ROLE 보다 넓고, SECURITY DEFINER 꼴은 앱이 고르는 것이라 방어가 아님을 함께 적는다.
- 재측정의 마스터 대역도 운영처럼 앱 표 권한이 없고, 위험 경로는 스스로 앱 역할을 받아 SET ROLE 하는 꼴로 재현했다. 로컬 모델에서 마스터에게 남는 앱 역할 ADMIN 옵션은 만든 쪽이 받는 것이고, 운영에서 같은 옵션이 있었는지는 원천이 말하지 않아 본문에 쓰지 않았다.
- 원격 실행기(운영의 명령 실행 도구)가 셸 신호 종료를 어떤 종료 상태로 돌려주는지는 재지 않았다.
