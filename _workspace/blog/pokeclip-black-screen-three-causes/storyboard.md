## 영상 1 — StageUnblock(반복, 345프레임 = 11.5초, 30fps)

배역: OBS 상자 → ① 변환(MediaMTX muxer) → ② 목록·조각 → ③ 브라우저(hls.js) → 화면(검은 상자). 상자 사이 화살표. 패킷(점)이 왼쪽에서 오른쪽으로 간다(휴대폰판은 위에서 아래로).

| 프레임 | 일 |
|---|---|
| 0–20 | 제목 · 상자 · 화살표 등장. 화면 상자는 검정 |
| 20–50 | 점이 OBS → ① 로 |
| 50–95 | ① 빨강, 위에 「muxer 오류 반복」 |
| 95–110 | ① 청록(통과), 아래 「오류 0건」. 빨간 이름표 사라짐 |
| 110–140 | 점이 ① → ② |
| 140–185 | ② 빨강, 「GAP 7개 · 401」 |
| 185–200 | ② 청록, 「GAP 0」 |
| 200–230 | 점이 ② → ③ |
| 230–275 | ③ 빨강, 「생성자 예외」 |
| 275–290 | ③ 청록, 「설정 짝 추가」 |
| 290–310 | 점이 ③ → 화면 |
| 310–345 | 화면이 청록 면으로 바뀌고 「재생 · 되감기」. 끝 프레임 = 포스터(posterFrame 330) |

끝 프레임: 세 단계 모두 청록 · 각 아래 통과 증거 · 화면 「재생 · 되감기」. 혼자서도 「세 단계를 통과해 재생」이 읽힌다. 11월 정정(①의 원인 설명, ②가 화면을 막지 않았을 가능성)은 캡션과 본문이 말한다.
