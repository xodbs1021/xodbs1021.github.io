# 콘티 — LiveVsRewindPath (반복 영상 10초, 300프레임, 휴대폰판 있음)

무엇이: 시청자 → CloudFront → (내부 ALB → 미디어 상자 EC2) / (S3 rewind). 두 요청이 같은 CloudFront에서 갈라진다.
순서: 0–20 상자 등장 → 30–130 청록 패킷(라이브 목록)이 시청자→CloudFront→내부 ALB→EC2, 지난 선이 청록으로 남고 EC2 상자가 청록, 150 이름표 「/live → EC2」 → 170–250 청록 패킷(되감기 조각)이 시청자→CloudFront→S3, 250 S3 청록, 265 이름표 「/dvr · /vod → S3」 → 300까지 정지.
끝 프레임(포스터 290): 두 길이 모두 청록으로 칠해져 있고 이름표 둘이 보인다. 혼자서도 「라이브는 EC2, 되감기는 S3」가 읽힌다.
소재: 생성 이미지 없음(Flow 부품만). 수치 없음(개념도).
